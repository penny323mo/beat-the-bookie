# Beat the Bookie v2 — Round 0 Build Report

## 1. 概述 (Overview)

本輪升級將「你估得贏莊家嗎？ (Beat the Bookie)」由原本僅支援西甲擴展為完整的 **v2 全面升級版**：
- **八大歐洲頂級賽事**：五大聯賽（英超、西甲、意甲、德甲、法甲）及三大歐洲盃賽（歐聯、歐霸、歐協聯），跨越 5 個賽季（2021/22 至 2025/26），全庫共有 **11,188 場真實比賽**。
- **雙重投注玩法**：支援傳統 **1X2（主/和/客）** 及 **亞洲讓球盤（Asian Handicap，共有 8,908 場比賽支援）**。
- **隨時「換一場」(Match Reroll)**：在下注確認/揭曉前，玩家可點擊「換一場 🔄」按鈕（或按快捷鍵 <kbd>R</kbd>），從同一個篩選池中隨機抽換另一場未用過之賽事（被換走的賽事不會被重複使用），不消耗比賽額度，AI 對手同步換至同一場賽事。下注/揭曉後或備用池用盡時自動停用，支援無限次換場，並於比賽介面與結算戰報中累計顯示換場次數。
- **盤口升跌走勢 (Odds Movement)**：每場提供最早開盤初盤至開賽前最後終盤之賠率升跌幅度（箭嘴及變動百分比，例如 `↓ 跌 2.8%`, `↑ 升 5.2%`），以及讓球盤口移位變更（升盤/降盤/水位受壓）。
- **進階賽事設定與即時賽事池統計**：主頁支援賽事多選（附「全選/五大聯賽/歐洲賽」快捷鍵）、賽季多選（附「全選/全部唔揀」快捷鍵）、局數與注碼自訂、可摺疊進階篩選（正宗粵語譯名搜尋球隊、日期區間），以及**即時連動計算「而家揀咗：N 場比賽可用」**。當可用場數不足（或為 0）時，自動鎖定開波按鈕並顯示廣東話原因。
- **輕量化架構與按需載入 (Lean Lazy-Loading)**：數據按賽事拆分為 `data/*.js` 獨立檔案，進入遊戲或切換篩選時透過動態 `<script>` 標籤按需載入，**完全零 `fetch()` / XHR，徹底避免瀏覽器本機雙擊 `file://` 下的 CORS 錯誤**，隨點隨玩。總檔案大小約 1.33 MB，遠低於 1.5 MB 目標上限。
- **正宗廣東話與移動端適配**：全庫 277 支參賽球隊均配備正宗香港/澳門譯名；全介面粵語口語表達；以 iPhone Safari (390px) 為首要適配標準，觸控目標全部 $\ge 44\text{px}$。

## 4. 亞洲讓球盤結算純函數與單元測試 (Asian Handicap Engine & Unit Tests)

在 `ah.js` 中實現純函數：
```javascript
settleAH(goalDiffForBackedSide, line, odds, stake) -> { profit, outcome: 'win' | 'halfwin' | 'push' | 'halfloss' | 'loss' }
```
- **核心算式**：
  - 支援單盤口（整數盤 $0, \pm 1, \pm 2$ 與半球盤 $\pm 0.5, \pm 1.5$）及分盤口（四分之一球 $\pm 0.25, \pm 0.75, \pm 1.25$）。
  - 分盤口自動將注碼拆分為兩半（`stake / 2`），分別於相鄰之兩組半球/整數盤上進行結算。
  - 獲利精確四捨五入至兩位小數（消除浮點精度誤差）。
  - 支援主客雙向：買主隊使用 $L = \text{AHh}$，買客隊使用 $L = -\text{AHh}$。
- **單元測試 (`tests/ah.test.js`)**：
  - 覆蓋 $0, \pm 0.25, \pm 0.5, \pm 0.75, \pm 1, \pm 1.25, -1.5, +2$ 全線盤口。
  - 覆蓋主客兩方勝（win）、贏半（halfwin）、走盤（push）、輸半（halfloss）、全輸（loss）所有分支。
  - 執行指令：`node tests/ah.test.js`
  - **測試結果**：**40 / 40 項測試 100% 通過（合格 ✅）**。
