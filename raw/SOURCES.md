# Data sources
- Leagues (E0 Premier League, SP1 La Liga, I1 Serie A, D1 Bundesliga, F1 Ligue 1), seasons 2021/22-2025/26: football-data.co.uk CSVs, https://www.football-data.co.uk/mmz4281/{2122..2526}/{E0,SP1,I1,D1,F1}.csv  (files: {LEAGUE}_{SEASON}.csv). Opening odds: B365H/D/A, AvgH/D/A, PSH.. ; closing: B365CH.., AvgCH.., PSCH..; Asian handicap opening AHh + B365AHH/AHA (+Avg/Max/P), closing AHCh + B365CAHH/CAHA etc.
- Cups (Champions League, Europa League, Conference League): footiqo.com database (odds sourced from 1xBet, CLOSING 1X2 only, plus O/U and BTTS). Files footiqo_<slug>.json: {"res":[{cols,rows}], "odds":[{cols,rows}]} — join results and odds on column `id`. matchDate format DD-MM-YY HH:MM. NO opening odds and NO Asian handicap for cups. Use seasons 2021/2022-2025/2026 only.
