# 「你估得贏莊家嗎？」(Beat the Bookie v2)

一個以**歐洲五大聯賽及三大歐洲盃賽真實數據**（2021/22 至 2025/26 共 5 個賽季，合共 11,188 場真實比賽）運行的單頁足球博彩模擬對決遊戲。

純粹前端單頁應用（SPA），直接雙擊 `index.html`（`file://` 協議）即可順暢遊玩，**無需架設任何伺服器，無需聯網，無任何外部 CDN 或字體依賴，完全相容離線運行**。

---

## 🌟 v2 全新升級亮點

1. **八大頂級賽事庫（共 11,188 場真實比賽）**：
   - **五大聯賽**：英超 (EPL)、西甲 (La Liga)、意甲 (Serie A)、德甲 (Bundesliga)、法甲 (Ligue 1)
   - **歐洲三大盃賽**：歐洲聯賽冠軍盃 (UCL)、歐霸盃 (UEL)、歐洲協會聯賽 (UECL)
   - 跨越 2021/22 至 2025/26 五個賽季，支援多選組合。
2. **雙重玩法模式（Bet Mode）**：
   - **1X2（主/和/客）**：傳統勝和負玩法，提供莊家抽水率計算及剔除抽水後嘅真實勝率。
   - **亞洲讓球盤（Asian Handicap）**：真實讓球盤結算（支援平手、受讓/讓半球、平半、半一、一球、球半等全盤/半盤/走盤規則）。
3. **初盤 vs 終盤走勢分析（Odds Movement）**：
   - 即時追蹤由最早開盤到開賽前終盤嘅賠率升跌與百分比幅度（例如 `↓ 跌 2.8%`, `↑ 升 5.2%`）。
   - 亞洲盤模式展示初盤讓球盤口至終盤盤口移位（升盤/降盤）與水位受壓變化。
4. **精準進階篩選與即時場數統計（Live Pool Count）**：
   - 支援依指定球隊（全庫 277 支球會均具備香港/澳門正宗粵語譯名）及日期區間進階篩選。
   - 介面即時連動顯示「**而家揀咗：N 場比賽可用**」，若可用場數不足（或為 0）自動鎖定開波按鈕並提示廣東話原因。
5. **高效輕量化按需載入（Lean Lazy-Loading）**：
   - 數據庫按賽事拆分為極度精簡的檔案（`data/*.js`），總檔案體積約 1.33 MB（嚴格壓在 1.5 MB 上限內）。
   - 玩家點選賽事時透過動態 `<script>` 標籤按需載入，完全避免瀏覽器本機 `file://` 下 `fetch()` 被 CORS 阻擋嘅問題。
6. **獨立純函數讓球結算模組與單元測試**：
   - `ah.js` 實現純函數 `settleAH(goalDiff, line, odds, stake)`。
   - 附帶無依賴單元測試套件 `tests/ah.test.js`，覆蓋所有盤口及各類主客盤局。

## ⚽ 遊戲玩法與規則

1. **開波設定（主頁面）**：
   - **賽事選擇**：英超、西甲、意甲、德甲、法甲、歐聯、歐霸、歐協聯（支援「全選」、「五大聯賽」、「歐洲賽」快速切換鍵）。
   - **賽季選擇**：2021/22 至 2025/26 自由多選。
   - **投注玩法**：1X2 (主/和/客) 或 亞洲盤 (讓球盤)。選擇亞洲盤時只會挑選具備讓球數據之聯賽場次。
   - **盤口類型**：初盤 (最早開盤) 或 終盤 (開賽前最後盤口)。歐洲賽僅設終盤 1X2。
   - **局數與注碼**：可選 5 / 10 / 20 / 30 場或自訂局數；每注 5 / 10 / 20 或自訂注碼。
   - **進階篩選**：可指定個別球隊或日期範圍。
   - **開波條件**：當可用賽事庫數量大於或等於指定局數時即可點擊「**開波！⚡**」。

2. **比賽對決流程**：
   - 系統依據你的設定隨機挑選賽事。
   - 雙方初始本金相同（預設 100 注）。
   - **下注操作**：
     - **換一場（Reroll）**：在下注確認/揭曉前，若對當前對局不滿意，可隨時點擊「**換一場 🔄**」（或按鍵盤 `R`）。系統會從目前篩選池抽取未曾使用過嘅隨機新比賽進行替換，不扣除場次，AI 對手同步換至相同新比賽。無限次數換場（只要備用池有剩餘比賽），介面及終局戰報均會顯示換場計數。
     - **1X2 模式**：點擊「主勝 (1)」、「和局 (X)」或「客勝 (2)」（快捷鍵：`1`、`X`、`2`）。
     - **亞洲盤模式**：點擊「主隊讓球盤」或「客隊讓球盤」（快捷鍵：`1` 買主、`2` 買客）。
     - **精選波膽加賞**：可選猜測全場入球比數（0–9 球），命中額外獲賞 **+20 注**！
   - **對抗跟莊熱門 AI**：
     - 虛擬對手每場固定盲買莊家開出嘅熱門（1X2 買最低賠率；亞洲盤買水位較低方）。
   - **揭曉賽果**：
     - 點擊「**揭曉賽果 📢**」（或按 `Space` / `Enter`），即時查看完場比數、半場比數與結算盈虧。

3. **亞洲盤結算規則**：
   - 單盤口（如 $0, \pm 0.5, \pm 1$）及分盤（如 $\pm 0.25, \pm 0.75$ 拆分為兩半注碼）：
     - **贏足全盤 (win)**：獲利 $+\text{stake} \times (\text{odds} - 1)$
     - **贏半個盤 (halfwin)**：獲利 $+\frac{\text{stake}}{2} \times (\text{odds} - 1)$
     - **走盤退注 (push)**：退回全部注碼，損益為 $0$
     - **輸半個盤 (halfloss)**：虧損 $-\frac{\text{stake}}{2}$
     - **全輸 (loss)**：虧損 $-\text{stake}$

4. **終局戰報**：
   - 完場後展示勝負判定（**🏆 贏咗莊家！ / 📉 輸咗畀莊家 / 🤝 打和！**）。
   - 統計最終本金、淨損益、勝出率、波膽獎金、投資回報率 (ROI %)，並刷新 `localStorage` 最高紀錄。
   - 附逐場詳細賽果、盤口變動、個人投注與每注盈虧清單。

## ⌨️ 鍵盤快捷操作

- `1`：選擇主隊（1X2 主勝 或 亞洲盤主隊）
- `X` 或 `0`：選擇 1X2 和局
- `2`：選擇客隊（1X2 客勝 或 亞洲盤客隊）
- `R` 或 `r`：換一場（抽換當前比賽）
- `Enter` 或 `Space`：
  - 開波按鈕 / 確認投注並揭曉賽果 / 推進至下一場 / 戰報頁再玩一轉

## 🧪 執行單元測試

專案附帶純 JavaScript 的 Asian Handicap 結算單元測試套件，完全零外部依賴：

```bash
node tests/ah.test.js
```

測試涵蓋全線盤口（$0, \pm 0.25, \pm 0.5, \pm 0.75, \pm 1, \pm 1.25, -1.5, +2$）及主客兩瓣之五種結算結果（win, halfwin, push, halfloss, loss），全數 40 項測試 100% 通過。
