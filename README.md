# 「你估得贏莊家嗎？」(Beat the Bookie)

一個以**西甲真實數據**（2024/25 及 2025/26 賽季，來自 football-data.co.uk）運行的單頁足球博彩模擬對決遊戲。

純純粹粹的前端單頁應用（SPA），直接雙擊 `index.html`（`file://` 協議）即可順暢遊玩，**無需架設任何伺服器，無需聯網，亦無需加載任何 CDN 或外部字體**。

---

## ⚽ 點樣玩（遊戲玩法）

1. **開波準備**：
   - 喺主頁選擇你想挑戰嘅賽季：**2025/26 賽季**（最新 380 場）、**2024/25 賽季**（經典 380 場）或**兩季混合**（全庫 760 場）。
   - 查閱你儲存喺本機（`localStorage`）嘅個人最高本金紀錄。
   - 點擊「**開波！⚡**」開始對決。

2. **比賽流程（每局 10 場）**：
   - 每一局系統會從你揀選嘅賽事庫中隨機抽出 **10 場不同真實賽事**。
   - 玩家初始本金為 **100 注**，每場固定下注 **10 注**。
   - 每場會展示：對賽球會（粵語譯名 + 原文英文 + 專屬球會盾徽）、開賽前 1X2 十進制賠率、**剔除莊家抽水後嘅真實勝率**（Margin-removed Implied Probability）以及**莊家抽水率（Margin %）**。最低賠率選項會標註為「**莊家熱門 🔥**」。
   - **下注選擇**：
     - 點擊「**主勝 (1)**」、「**和局 (X)**」或「**客勝 (2)**」大按鈕（亦可直接撳鍵盤 `1`、`X`、`2` 鍵）。
     - **可選兼估精確波膽**：可自由開啟波膽計數器（預設為空白未選），猜測全場入球比數（0–9 球）；猜中波膽即刻額外獎勵 **+20 注**（猜錯無懲罰）！
   - 點擊「**揭曉結果 📢**」（或撳鍵盤 `Enter` / `空白鍵`）睇即時全場賽果、半場比數同全場射門數據。

3. **賠率與結算公式**：
   - **剔除抽水真實勝率**：$p_i = \frac{1/o_i}{\sum (1/o_j)} \times 100\%$（嚴格保證三瓣顯示總和為 100.0%）
   - **莊家抽水率**：$(\sum \frac{1}{o_j} - 1) \times 100\%$
   - **1X2 損益**：
     - 猜中獲利：$+10 \times (\text{賠率} - 1)$
     - 猜錯損失：$-10$ 注
   - **精選波膽獎賞**：猜中全場比數額外 $+20$ 注。
   - **本金允許變為負數**，不會提前結束，完整打足 10 場。

4. **跟莊家熱門 AI（基準對手）**：
   - 同場有一位虛擬對手每場自動固定買入賠率最低嘅「莊家熱門」。
   - 每一場會即時對比你同 AI 嘅本金變動。

5. **終局戰報**：
   - 完成 10 場後進入結算畫面，對比你與莊家熱門嘅最終本金、1X2 命中率、波膽命中數、投資回報率（ROI %）以及終極勝負評判（**贏咗莊家 / 輸畀莊家 / 打和**）。
   - 附有詳盡的逐場賽果回顧清單。若打破個人最高紀錄，會即時自動保存至 `localStorage`。

## ⌨️ 鍵盤快捷操作

- `1`：選擇「主勝」
- `X` 或 `x`：選擇「和局」
- `2`：選擇「客勝」
- `Enter` 或 `Space`：
  - 當前焦點在特定按鈕/輸入框時，由該控制項原生觸發操作。
  - 當前焦點在頁面本體時，作為全域快捷鍵：
    - 主頁：開波
    - 比賽中：確認揭曉結果 / 推進下一場
    - 結算頁：再玩一轉
- 方向鍵（`←` / `→` / `↑` / `↓` / `Home` / `End`）：在主頁賽季單選群組（Radiogroup）中巡迴切換賽季。

## 🛠️ 重新生成數據庫（Regenerate Data）

如需由原始西甲 CSV 數據重新生成 `data.js`，只需使用 Python 3 標準庫（無需安裝任何第三方套件）：

```bash
python3 build_data.py
```

腳本會自動讀取 `SP1_2526.csv` 及 `SP1_2425.csv`（以 `utf-8-sig` 編碼處理），清洗並轉換為符合規格之 JSON 格式，輸出至 `data.js`（定義 `window.MATCHES`）。
